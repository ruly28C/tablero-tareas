# Antes del taller (10 minutos)

Haz esto antes de la sesión 1 para que no perdamos tiempo instalando.

1. **Crea tu cuenta en GitHub:** https://github.com/signup. Usa un nombre de usuario serio: lo vas a poner en tu CV.
2. **Instala Git:** https://git-scm.com/downloads. En Windows deja todas las opciones por defecto.
3. **Instala Visual Studio Code** (si no lo tienes): https://code.visualstudio.com
4. **Verifica.** Abre VS Code, menú Terminal → Nueva terminal, y escribe:

   ```
   git --version
   ```

   Si sale un número de versión, ya quedó. Si dice que no reconoce el comando, cierra VS Code y vuelve a abrirlo.

5. **Configura tu nombre y correo** (el mismo correo de tu cuenta de GitHub):

   ```
   git config --global user.name "Tu Nombre"
   git config --global user.email "tucorreo@ejemplo.com"
   ```

6. **Llena el formulario de registro:** [LIGA DEL FORMULARIO]

El día del taller ten lista tu computadora con internet, Git, VS Code y tu sesión de GitHub abierta en el navegador.
