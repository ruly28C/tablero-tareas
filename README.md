# Tablero de tareas

Proyecto del Taller de Git y GitHub (ITSON).

## ¿Qué es?

Una app web sencilla para anotar tareas: agregar, marcar como hecha y borrar. Las tareas se guardan en el navegador.

## Cómo correrlo

Abre `index.html` en el navegador. No necesita instalar nada.

## Cómo usarlo

1. Escribe una tarea y presiona **Agregar**.
2. Haz clic en la tarea para marcarla como hecha.
3. Presiona **X** para borrarla.
